# 트립어드바이저 (TripAdvisor) 사이트 자동화 가이드

## 1. 보안 및 안티봇 (DataDome)
- **보안 솔루션**: DataDome (`geo.captcha-delivery.com`) 탑재.
- **돌파 전략**:
  - 첫 방문 시 `webctl browser reveal`로 화면을 열어 사용자가 슬라이더 퍼즐 캡차를 1회 해결.
  - 해결 후 발급된 DataDome 세션 쿠키가 `managed-mirror` 프로필에 영구 보존되어, 이후 백그라운드(`headless: true`) 모드 및 브라우저 재시작 후에도 차단 없이 다이렉트 통과 가능.

## 2. 뷰포트 크기 및 검색바 노출 (Viewport Critical Rule)
- 기본 헤드리스 창 크기(800x600 등)에서는 트립어드바이저 상단 날짜 및 객실/인원 선택 바가 모바일 햄버거 메뉴 및 숨김 레이어로 축소되어 타겟팅이 어려움.
- 따라서 반드시 시작 전 **1440x900 이상의 데스크톱 뷰포트(`Emulation.setDeviceMetricsOverride`)**로 크기를 지정해야 상단에 고정된 검색 필터 바가 온전히 노출됨.

## 3. 날짜 및 인원 설정 메커니즘 (Date & Guest Selection)
트립어드바이저 폼은 URL 쿼리스트링 전달만으로는 내부 SPA 상태가 갱신되지 않으므로, DOM 물리 클릭 이벤트(`Input.dispatchMouseEvent`)를 통해 설정해야 함:

### 1) 날짜(체크인/체크아웃) 선택:
- 체크인 버튼 클릭 -> 달력 오버레이 노출.
- 날짜 셀은 텍스트가 아닌 `aria-label` 속성(예: `aria-label="2026년 10월 3일"`)을 타겟팅하여 좌표 계산 후 마우스 클릭.
- 시작일(체크인)과 종료일(체크아웃)을 순서대로 클릭하면 자동으로 날짜 범위 확정.

### 2) 객실 수 및 인원(성인/어린이) 설정:
- 상단 `객실/고객 수` 버튼 클릭 -> 팝업 레이어 오픈.
- 단순 JS 증감이 먹히지 않으므로 `aria-label="객실 수를 한 개 더 많게 설정"` 및 `aria-label="성인 수를 한 명 더 많게 설정"` 버튼을 필요한 횟수만큼 좌표 클릭.
- 마지막으로 `업데이트` 버튼을 클릭하면 실시간 호텔 목록 재조회 및 가격이 자동 재계산됨.

## 4. 가격 데이터 해석 (Pricing)
- 호텔 목록에 표시되는 요금(예: `₩119,051`)은 **지정된 총 객실 수(예: 2개 객실)를 합산한 1박 기준 실시간 실제 요금**임.
- 예약 가능 여부는 `가격 보기` 또는 `예약 가능 여부 확인` 버튼이 활성화되어 요금이 노출되는 호텔들로 확인.
